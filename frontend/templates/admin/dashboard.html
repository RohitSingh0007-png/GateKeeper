Resource protection

{% if governor_mode == "enforced" %} The Governor is assigning tenant sessions to their cgroups. {% else %} How GateKeeper isolates tenants. In stub mode none of these controls are active yet. {% endif %}

{{ icon("cpu") }}CPU control

Each plan's CPU quota is written to the tenant cgroup's cpu.max, so the kernel scheduler caps it.

{{ icon("memory") }}Memory usage

Read from memory.current and capped by memory.max for the tenant's plan.

{{ icon("activity") }}Throttling

Detected from cpu.stat when the kernel holds back a tenant that reached its quota.

{{ icon("layers") }}Tenant isolation

Session pooling keeps each tenant on its own PostgreSQL backend process inside its own cgroup.
